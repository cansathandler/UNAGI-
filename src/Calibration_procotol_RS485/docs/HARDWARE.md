# ハードウェアとピン配置（protocol v3 / RS-485）

ESP-NOW 版からの変更の経緯は `../CHANGES_RS485.md` を参照。

## 構成

```
                      XT30（BATT+ / GND を数珠つなぎ）
ヘッド ──────── ノード 1 ──────── ノード 2 ── … ── ノード 10
  │  RS-485 A/B（2 本。GND は XT30 と共通）            │
  └ 終端 120 Ω (R18) + バイアス 390 Ω×2 (R16/R17)      └ 終端 120 Ω（JP で入れる）
```

- 終端は両端だけ。途中のノードのジャンパは開けておく。
- バイアスはヘッドだけ。ノードには入れない（並列で効きすぎる）。
- ID 1〜10 は配線順と関係ありません（各ノードの NVS に保存）。

## ノード（XIAO ESP32-C3）

| 信号 | XIAO | GPIO | 備考 |
|---|---|---|---|
| DRV8833 IN1（AIN1+BIN1 並列） | D2 | 4 | PWM 25 kHz、10 bit |
| DRV8833 IN2（AIN2+BIN2 並列） | D3 | 5 | PWM 25 kHz、10 bit |
| SP3485 DE + /RE | D4 | 6 | UART1 の RTS。10 kΩ プルダウン |
| DRV8833 nFAULT | D5 | 7 | 内部プルアップ。Low = 異常 |
| SP3485 DI | D6 | 21 | UART1 TX |
| SP3485 RO | D7 | 20 | UART1 RX。10 kΩ プルアップ |
| SS39ET S1 | A0 | 2 | ADC1 |
| SS39ET S2 | A1 | 3 | ADC1 |
| SYNC 出力 | D10 | 10 | SYNC-1 試験用（任意） |

- 駆動はスローディケイ（片側 100 %、もう片側を PWM）。u = 0 のときは両方 0（惰性）。
- DRV8833 の SLP はキャリア上でプルアップ。ファームからは止められないので、
  起動直後に IN1 = IN2 = 0 を出すのが最初の処理になっています。
- 起動中（ファームが動く前）は D4 がプルダウンで Low なので、ROM の起動ログが D6 に出ても
  バスには出ません。

| 信号 | XIAO | GPIO | 備考 |

| INA226 ALERT | D2 | 4 | 過電流で STOP + 給電 OFF |
| SP3485 DE + /RE | D3 | 5 | UART1 の RTS。10 kΩ プルダウン |
| INA226 SDA | D4 | 6 | |
| INA226 SCL | D5 | 7 | |
| SP3485 DI | D6 | 21 | UART1 TX |
| SP3485 RO | D7 | 20 | UART1 RX。10 kΩ プルアップ |

## バスの設定

| 項目 | 値 | 変え方 |
|---|---|---|
| 速度 | 1 Mbps, 8N1 | `-DBUS_BAUD=500000`（ヘッド・ノード両方） |
| DE 制御 | UART の RS-485 半二重モード | `-DBUS_HW_DE=0` でソフト制御 |
| フレーム | `0x7E, len, payload, CRC16`（HDLC 式バイトスタッフィング） | `include/unagi_bus.h` |
| 最大 payload | 250 バイト | |

## 確認のしかた

| 確認 | 方法 | 正常 |
|---|---|---|
| A/B の向き | 無通信時に A−B をテスタで | 約 +0.24 V（3.3 V・390 Ω バイアス、両端終端） |
| 終端の入れすぎ | 同上 | 0.1 V を切るなら終端が 3 か所以上ある |
| DE の切替 | ノード D4 をオシロで、ヘッドから `peek <id> 1` | 返事の間だけ約 0.1〜0.5 ms High |
| 受信 | ノード USB で `bus` | `rx_ok` が 20 回/秒で増える |
| 誤り | ヘッドで `bus` | `crc=0`、`timeouts` がほぼ増えない |

## その他の注意（v2 から変わらないもの）

- ホール2本は ADC1（GPIO0〜4）。ADC2 は使えません。
- ホール出力は 2.5 V 以下に収める（11 dB 減衰時の実用レンジ）。
- `PWM_HZ` は `CTRL_HZ` の整数倍（25 kHz = 25 × 1 kHz）。崩すと角度に低周波のうなりが乗る。
- `UNAGI_MAX_SAMPLES` = 4000（14 B × 4000 = 56 kB）。200 Hz で 20 秒、1 kHz で 4 秒。
